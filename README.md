# Tesla Carrera GT V10 Engine Sound Simulator 🏎️⚡

Веб-приложение для воспроизведения реалистичного адаптивного звука легендарного двигателя **Porsche Carrera GT (5.7L V10)** во время движения на автомобиле Tesla (или любом другом электромобиле), а также в интерактивном симуляторе.

## Возможности

1. **Web Audio API синтезатор V10:**
   - 8-слойная динамическая интерполяция звука мотора (нагрузка / накат / обороты от 920 до 8400+ об/мин).
   - Прямозубый вой трансмиссии, переключения передач (`gearup` / `geardn`).
   - Хардкорная отсечка (Rev limiter cut) на 8400 об/мин с пулеметными отстрелами.
   - Прострелы и хлопки в выхлопную трубу (Pops & Bangs / Overrun) при резком сбросе газа.

2. **Интерактивная 3D-педаль газа:**
   - Реалистичная алюминиевая педаль со шпильками с поддержкой аналогового нажатия мышью, пальцем (Touch/Drag) или клавишами (`Space`, `W`, `S`).
   - Режимы трансмиссии: `N` (перегазовки на месте), `D` (виртуальная КПП 1-6 передач), `M` (ручной режим `Q`/`E`).
   - Кнопки быстрого действия: «💥 Перегазовка (Blip)», «🚀 Launch Control (старт с 4800 об/мин)», «🛑 Тормоз».

3. **Высокоточная телеметрия GPS + Акселерометр:**
   - Чтение аппаратных спутниковых координат `navigator.geolocation` с флагом `enableHighAccuracy: true` и нулевым кэшем (`maximumAge: 0`).
   - Вычисление мгновенной скорости и дифференциального расстояния по формуле гаверсинусов (Haversine).
   - 1D фильтр Калмана для подавления погрешности и дрейфа спутников на светофорах.
   - Слияние данных с акселерометром смартфона (`DeviceMotionEvent` 30-60 Гц) — мгновенная реакция звука на нажатие педали газа до того, как среагирует GPS.

4. **P2P связка Tesla ↔ Телефон (WebRTC / PeerJS):**
   - На экране Теслы генерируется 4-значный код и QR-код.
   - Телефон сканирует QR-код, подключается напрямую по WebRTC DataChannel и передает метрики перегрузок и скорости с нулевой задержкой.

## Как запустить прямо сейчас на компьютере:

1. Запустите файл `start_local_test.bat` (он поднимет локальный сервер и откроет `http://localhost:8000`).
2. Нажмите **`START ENGINE`** для запуска звука.
3. Нажимайте на педаль газа мышкой или зажимайте `Space` / `W` на клавиатуре!

---

## Как опубликовать на GitHub Pages:

1. Создайте бесплатный репозиторий на GitHub (например, `tesla-v10-sound`).
2. Загрузите файлы из этой папки (`index.html`, `style.css`, папки `js/` и `sounds/`).
3. В настройках репозитория: **Settings** $\rightarrow$ **Pages** $\rightarrow$ выберите ветку `main` и нажмите **Save**.
4. Через 1 минуту сайт будет доступен по ссылке `https://<ваш-логин>.github.io/tesla-v10-sound/`.
5. Откройте эту ссылку в браузере Теслы и на смартфоне!
